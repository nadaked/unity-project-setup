## [1.0.0] - 2026-08-01

### Added

* Initial release of Nadaked Project Setup
* Added `Tools → Setup → Create Folders`
* Added `Tools → Setup → Install Essential Packages`
* Added `Tools → Setup → Import Essential Assets`
* Added automatic `_Project` folder creation
* Added default project subfolders:

  * Animations
  * Editor
  * Materials
  * Models
  * Prefabs
  * Resources
  * Scenes
  * ScriptableObjects
  * Scripts
  * Settings
  * Textures
* Added automatic movement of existing `Scenes` and `Settings` folders
* Added automatic movement of `InputSystem_Actions.inputactions`
* Added deletion of Unity template files:

  * `Readme.asset`
  * `TutorialInfo`
* Added automatic Unity package installation
* Added UniTask installation
* Added PrimeTween installation
* Added Alchemy installation
* Added Unity Utils installation
* Added Selection History and Favorites installation
* Added Unity UI installation
* Added automatic PrimeTween scoped registry configuration
* Added TextMesh Pro Essential Resources import
* Added Editor-only assembly definition
* Added local and Git-based Unity Package Manager support
